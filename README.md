# AI-Powered Course Registration System

## Description
This project is a Django-based web application for course registration.
It allows users to register for courses and receive intelligent course recommendations
using a Machine Learning model based on the user’s profile and interests.

The system also includes a demo quiz for testing user knowledge and
automatically generates a certificate after course completion.

## Features
-->User registration and profile management
--> Course registration system
--> Machine Learning based course recommendation
--> User profile based suggestions
-->Demo quiz for assessment
-->Certificate generation after completion
-->Simple and user-friendly interface#

## Technologies Used
--> Django (Backend Framework)
--> Python
--> Machine Learning (Recommendation Model)
-->HTML, CSS, Bootstrap
--> SQLite / MySQL (Database)

## How It Works
1. User creates an account and completes profile
2. User registers for available courses
3. ML model recommends courses based on user profile
4. User takes a demo quiz
5. System evaluates performance
6. Certificate is generated after completion
